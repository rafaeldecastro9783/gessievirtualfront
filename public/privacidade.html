Política de privacidade da Gessie

A Gessie é uma assistente de uso pessoal e privado do seu autor. Não há outros usuários.

Dados acessados

  • Google Agenda (somente leitura): compromissos de hoje e de amanhã, para avisos e para o resumo do dia.
  • Gmail: leitura de mensagens não lidas para resumo e envio de e-mails pedidos pelo próprio autor (por exemplo, cobranças aos seus clientes).

Como os dados são usados e guardados

  • Os dados são processados no computador do autor e não são vendidos, compartilhados com terceiros nem usados para publicidade.
  • Os tokens de acesso ficam guardados apenas nesse computador, com acesso restrito.
  • Trechos podem ser enviados a serviços de IA contratados pelo autor (Anthropic) somente para gerar resumos e respostas pedidos por ele.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
